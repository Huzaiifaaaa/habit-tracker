# Habit Tracker

A minimal habit matrix built with React, Vite, and Lucide icons. Tracks consecutive daily streaks, updates states instantly, and persists metrics locally.

## 🚀 Live Deployment
- **Production URL:** [https://habit-tracker-dw.vercel.app/](https://habit-tracker-dw.vercel.app/)

## 🛠️ Local Development Setup

Follow these steps to run the application locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Huzaiifaaaa/habit-tracker
   cd habit-tracker
   cd habit-tracker

2. **Install Dependencies:**
```bash
npm install

```

3. **Run Development Server:**
```bash
npm run dev

```

4. **Build for Production:**
```bash
npm run build

```
